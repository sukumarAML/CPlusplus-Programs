# Scenario Based Questions

1. ATM Login Authentication System

Scenario:

If the entered PIN matches the stored PIN (1234), allow access; otherwise deny access after 3 attempts.

Question:

Write a C++ program using class to simulate ATM authentication.

2. Phishing Email Detection System

Scenario:

If an email contains words like "WIN", "FREE", "URGENT", it is considered a phishing email.

Question:

Write a C++ program using class and encapsulation to detect whether an email is phishing or legitimate.

3. Password Strength Checker

Scenario:

A secure system requires:

• Minimum 8 characters
• At least one digit
• At least one special character
Question:

Develop a C++ program to validate password strength using OOPS.
